### 4.1 顺带发现并修复的隐患（密钥外置时暴露）

- **`AlipayConfig.alipayClient()` 未配置时返回 `null`**，而 `AlipayService` 用 `@Resource` 注入，
  Spring 抛 `BeanNotOfRequiredTypeException: ... was actually of type NullBean` → **应用无法启动**。
  此前因仓库硬编码了真实支付宝凭据（`isConfigured()` 恒 true）而从未暴露。
  已改为 `@Autowired(required = false)`，未配置时走模拟支付，应用可正常启动。
- **上传目录与静态资源目录不一致**：`FileController` 用 `user.dir + "/files/"`（= `springboot/files`），
  实际文件在 `code2026/files`；且 `@PathVariable String fileName` 未指定名称、编译未开 `-parameters`，
  会抛 `IllegalArgumentException: Name for argument of type [java.lang.String] not specified`。
  已新增 `J/utils/FileStorage.java` 统一解析目录，供控制器与静态映射共用。
