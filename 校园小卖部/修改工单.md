### 5.1 本轮排查出的两个重要问题（均已修复/确认）

- **`-parameters` 编译参数缺失（影响面最大）**：本项目用 `dependencyManagement` import
  `spring-boot-dependencies` 而非继承 `spring-boot-starter-parent`，javac 因此不带 `-parameters`。
  后果：所有**未显式命名**的 `@PathVariable`/`@RequestParam` 运行期抛
  `IllegalArgumentException: Name for argument of type [...] not specified` → 接口 500。
  实测受影响：`/orders/selectPage`、`/collect/selectPage`、`/comment/selectPage`、`/post/selectPage`、
  `/files/download/{fileName}` 等。已在 pom 补 `<parameters>true</parameters>`，
  重新编译后这些接口全部恢复（实测 code=200）。
- **仓库内 BCrypt 哈希无效（已用 BCrypt 实测）**：`code2026.sql` 与 `update_passwords.sql` 的哈希
  **既不匹配 `admin` 也不匹配 `123456`**。即照脚本初始化数据库后**无法登录**。
  本轮未擅自替换（等同重置密码，属业务决定），列为待办。
